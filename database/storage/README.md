# DATABASE STORAGE ARCHITECTURE
This directory catalogues active buckets, file extension matrices, size limit definitions, and access permissions.

## Storage Buckets Created
- `documents`: Secure, private bucket for PDFs, docx, and txt files (e.g. letters, admissions).
- `images`: Publicly readable bucket for student avatars, logos, and UI graphics.
- `media`: Multi-media bucket for recording academic sessions and training videos.
- `reports`: Financial audits, grade distributions, and census sheets.
- `backups`: Encrypted SQL and cluster backup archives.
- `ai-files`: Saved model weights, training sets, and semantic logs.
- `temporary-files`: Volatile scratchpad for file uploads and transfers.
- `archives`: Long-term cold storage archives.
