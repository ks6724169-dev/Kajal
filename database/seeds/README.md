# DATABASE METADATA SEED FILES
This directory contains initial static reference data used to seed global lookups (e.g. locales, countries, default currencies, system versions) upon schema initialization.

## Seeds Applied
- **Countries**: Standard ISO lookup profiles (India, United States, UAE, Singapore, United Kingdom).
- **Languages**: Default localization codes (English, Hindi, Arabic, Spanish).
- **Currencies**: Regional monetary standards (INR, USD, AED, GBP, EUR).
- **System Version**: Initializes the GEOS v12.0 reference record.
